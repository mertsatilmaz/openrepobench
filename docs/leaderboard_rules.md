# Leaderboard Rules

Leaderboard entries must be reproducible.

## Required artifacts

- Result JSON files
- Logs
- Patches
- Agent configuration
- Model configuration
- Cost estimate
- Runtime environment

## Disallowed

- Mixing single-attempt and best-of-N results
- Mixing internet-enabled and internet-disabled runs
- Modifying tests unless explicitly allowed
- Reporting hidden-set performance without verified logs
