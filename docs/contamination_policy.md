# Contamination Policy

Static public benchmarks are eventually trained on. OpenRepoBench should treat contamination as inevitable and design around it.

## Controls

- Public seed tasks
- Hidden leaderboard tasks
- Fresh task waves
- Canary strings
- Retired task releases
- Submission disclosure requirements
- Deduplication against known benchmark sets

## Rotation

Hidden tasks should be periodically retired into the public set and replaced with fresh tasks.
